# 📸 **Piku – Event Photo Documentation App**

Piku is a mobile application built with React Native (Expo) that allows users to document events collaboratively through photos. Users can create events, invite others via QR codes, capture and upload photos in real time, and edit images directly inside the app.

This project was developed as the final project for DCIT 26 – Application Development and Emerging Technologies.

## ✨ **Key Features**

Google-style sign-in and user profiles

Create and join events using QR codes

In-app camera with real-time photo upload

Event-based photo galleries

Built-in photo editor (filters, stickers, text)

Firebase-powered backend (Firestore & Storage)

## 🛠 **Tech Stack**

React Native + Expo

Expo Router

Firebase (Firestore & Storage)

TypeScript
